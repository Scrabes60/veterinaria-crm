# Veterinaria CRM — Starter (Next.js + Supabase)

## Requisitos
- Node.js 18+
- Cuenta en Supabase (gratis)
- (Opcional) Clave de The Cat API

## Cómo correr
1) `npm install`
2) Copia `.env.local` desde `.env.example` y pon tus claves.
3) `npm run dev` y abre http://localhost:3000

## Despliegue
- Sube el repo a GitHub y conéctalo en Vercel.
- Configura las mismas variables `.env` en Vercel.

## BD (SQL)
- Importa `db/schema.sql` en Supabase (SQL Editor).
- Activa RLS si no se activa automáticamente.
